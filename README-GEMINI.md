# Vindora Gemini Telegram Update

## الملفات
- `main.py`: نسخة محدثة من معالج Telegram.
- `gemini_engine.py`: محرك الإجابة باستخدام Gemini.
- `config.py`: يقرأ الأسرار من متغيرات البيئة.
- `requirements.txt`: المكتبات المطلوبة.
- `.env.example`: مثال للإعدادات؛ انسخه إلى `.env` ولا ترفع `.env` إلى GitHub.
- `knowledge/vindora_knowledge.md`: قاعدة معرفة أولية قابلة للتحديث.

## خطوات التثبيت
1. احتفظ بنسخة احتياطية من ملفات المشروع وقاعدة `vindora.db`.
2. استبدل `main.py` و`config.py` و`requirements.txt` بالنسخ الموجودة في الحزمة.
3. أضف `gemini_engine.py` ومجلد `knowledge`.
4. ثبّت المكتبات:
   `pip install -r requirements.txt`
5. انسخ `.env.example` إلى `.env`، ثم ضع:
   - توكن Telegram جديد بعد إلغاء القديم.
   - مفتاح Gemini API من Google AI Studio.
   - Telegram Admin IDs.
6. شغّل:
   `python main.py`

## إعداد الاستضافة
إذا كانت الاستضافة توفر Environment Variables، استخدمها بدل ملف `.env`.
لا ترفع `.env` إلى GitHub، وأضف هذا السطر إلى `.gitignore`:
`.env`
